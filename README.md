# Дневник-планировщик задач в Telegram

Telegram-бот, который помогает вести ежедневный дневник и планировать задачи. Автоматизирует рутину "утро-вечер": вечером задаёт вопросы об итогах дня, утром показывает планы и мотивирует.

## Какую рутину автоматизирует

Раньше я каждый вечер вручную записывал в заметки:
- Что сделал за день
- С какими сложностями столкнулся
- Какие задачи на завтра

Утром открывал заметки, вспоминал планы. Это занимало 10-15 минут в день и часто забывалось.

Теперь бот сам напоминает вечером, задаёт вопросы, сохраняет ответы. Утром показывает сводку и мотивирует.

## Установка и запуск

5. Настройте config.py
Создайте файл config.py в корне проекта:

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список команд |
| `/help` | Подробная справка по всем командам |
| `/evening` | Вечерний опрос: что сделал, сложности, планы на завтра |
| `/morning` | Утренняя сводка: задачи на день, вчерашний итог, цитата |
| `/today` | Задачи на сегодня со статусами (✅/⬜) и прогрессом |
| `/add <задача>` | Добавить задачу на сегодня |
| `/done <номер>` | Отметить задачу выполненной |
| `/delete <номер>` | Удалить задачу по номеру |
| `/note <текст>` | Добавить заметку/мысль |
| `/weekly` | Отчёт за последние 7 дней |

Хранение данных
Все данные хранятся в diary.json. Структура:
{
  "2026-10-26": {
    "tasks_planned": ["Задача 1", "Задача 2"],
    "tasks_done": ["Задача 1"],
    "difficulties": "Не хватило времени",
    "thoughts": "Нужно лучше планировать",
    "plans_for_tomorrow": ["Задача 2"]
  }
}

Краевые случаи и обработка ошибок
1. Файл diary.json не найден при первом запуске
Решение: функция load_diary() возвращает пустой словарь {}, бот продолжает работать.
2. Файл diary.json повреждён (невалидный JSON)
Решение: ловим json.JSONDecodeError, логируем ошибку, возвращаем пустой словарь.
3. Пользователь ввёл пустую строку в вечернем опросе
Решение: FSM всё равно сохранит ответ, но функция _parse_list() вернёт пустой список задач.
4. Пользователь написал /add без текста задачи
Решение: бот отвечает "❌ Напиши задачу после команды. Пример: /add Позвонить маме"
5. Пользователь написал /done abc (не число)
Решение: ловим ValueError, бот отвечает "❌ 'abc' — это не число. Напиши номер задачи."
6. Пользователь указал несуществующий номер задачи (/done 99)
Решение: проверяем индекс, бот отвечает "❌ Нет задачи с номером 99. Всего задач: 2"
7. Задача уже отмечена выполненной
Решение: проверяем, есть ли задача в списке tasks_done, бот отвечает "❌ Задача '...' уже отмечена выполненной"
8. Нет вчерашней записи при вызове /morning
Решение: функция get_entry() возвращает None, бот пишет " На сегодня задач пока нет. Добавь через /add <задача>"
9. Сетевая ошибка при подключении к Telegram API
Решение: в bot.py обёрнуто в try...except, ошибка логируется, бот не падает.
10. Пользователь написал /note без текста
Решение: бот отвечает "❌ Напиши заметку после команды. Пример: /note Хороший день был"
